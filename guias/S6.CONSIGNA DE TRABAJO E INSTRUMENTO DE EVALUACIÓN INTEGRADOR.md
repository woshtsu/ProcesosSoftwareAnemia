I. CONSIGNA DE TRABAJO INTEGRATORA DEL
PROYECTO DE ASIGNATURA

1. Propósito de la Evaluación

Consolidar e integrar de forma práctica los productos desarrollados en las Guías de
Trabajo de las Semanas 1 a 7, demostrando la capacidad del equipo para conectar el
problema organizacional de una empresa con el diseño del proceso TO-BE, la
selección/adaptación del ciclo de vida (tailoring), la arquitectura del software, la
estrategia de pruebas y la demostración funcional del Primer Incremento / Producto
Mínimo Viable (PMV).

2. Modalidad y Formato de Entrega

•  Modalidad: Grupal (Equipos de proyecto constituidos).
•  Entregables Obligatorios en Aula Virtual:

1.  Informe Académico Integrador (PDF): Estructurado según el formato

oficial adjunto.

2.  Presentación Visual (PDF/PPTX): Exactamente 7 diapositivas

diseñadas para la defensa del proyecto.

3.  Enlace al Repositorio de Código (GitHub/GitLab): Con el código
fuente del PMV, scripts de base de datos, pruebas automatizadas y
archivo README.md de despliegue.

•  Tiempo de Exposición: 7 minutos de exposición grupal + 5 minutos de defensa

oral individual (preguntas de dominio técnico).

Resultado y Valor).

    • Matriz de Responsabilidades RAE (Responsable de Ejecución,
Revisión y Aprobación).

DoD*) por Actividad.

➔ Tareas del Incremento 1.
    • Estimación de Esfuerzo, Matriz de Priorización (Valor/Riesgo) y
Plan de Trabajo (Cronograma/Sprint).
    • Mecanismos de Seguimiento, Control de Desviaciones e Indicadores
de Avance.

III. FORMATO DE EXPOSICIÓN DE 7
DIAPOSITIVAS VISUALES

(Estructura obligatoria de diapositivas para la defensa grupal de 7 minutos)

======================================================================
==================================
                 ESTRUCTURA DE EXPOSICIÓN: 7 DIAPOSITIVAS INTEGRADORAS
DEL PROYECTO
======================================================================
==================================

DIAPOSITIVA 1: PROBLEMA ORGANIZACIONAL Y PROPUESTA DE VALOR (AS-IS vs.
TO-BE)
----------------------------------------------------------------------
----------------------------------
• Esquema Visual: Comparativo visual "Proceso Reactivo AS-IS
(Manual/Retrasos)" vs. "Proceso Preventivo TO-BE (Software/Valor)".
• Contenido Clave:
  - Definición del problema central y brechas operativas principales.
  - Cadena de Valor: Datos ➔ Software ➔ Decisión ➔ Impacto
Organizacional.
  - Indicador de Valor objetivo (Ej. Reducción del tiempo de respuesta
de 2.5 h a 5 s).
• Pitch del Expositor (1.5 min): "Explicar cómo la solución resuelve
la pérdida de valor organizacional."

DIAPOSITIVA 2: SELECCIÓN Y ADAPTACIÓN (*TAILORING*) DEL MODELO DE
PROCESO
----------------------------------------------------------------------
----------------------------------

• Esquema Visual: Matriz de Factores del Proyecto + Diagrama del Ciclo
de Vida Adaptado.
• Contenido Clave:
  - Factores determinantes: Nivel de Incertidumbre, Complejidad
Técnica, Integración y Componentes de Datos/IA.
  - Justificación del Enfoque Híbrido (Ej. Iterativo/Incremental +
Scrum + Prácticas DevOps/MLOps).
  - Rechazo explícito del modelo Cascada tradicional o Scrum puro sin
ingeniería continua.
• Pitch del Expositor (1.5 min): "Sustentar por qué las
características del proyecto exigieron esta adaptación."

DIAPOSITIVA 3: ARQUITECTURA DE SOFTWARE DEL INCREMENTO 1 (PMV)
----------------------------------------------------------------------
----------------------------------
• Esquema Visual: Diagrama de Contenedores C4 (Nivel 2) + Cuadro de
Decisiones Arquitectónicas (ADRs).
• Contenido Clave:
  - Estructura tecnológica: Apps Móviles/Web, API Gateway,
Microservicios, Base de Datos y Caché.
  - ADRs críticos vinculados a Atributos de Calidad (Concurrencia,
Latencia, Disponibilidad).
  - Protocolos de comunicación (REST, WebSockets, gRPC).
• Pitch del Expositor (1.5 min): "Demostrar cómo la arquitectura
soporta los requerimientos no funcionales."

DIAPOSITIVA 4: ESTRATEGIA Y EJECUCIÓN DE PRUEBAS DE SOFTWARE
----------------------------------------------------------------------
----------------------------------
• Esquema Visual: Pirámide de Pruebas del Proyecto + Gráficos de
Cobertura de Código y Pruebas de Carga.
• Contenido Clave:
  - Cobertura de Pruebas Unitarias e Integración (Resultado Jacoco /
Istanbul / Jest).
  - Pruebas de Carga/Estrés ejecutadas (Resultados k6/JMeter: Latencia
p95 y Throughput RPS).
  - Cumplimiento de Criterios de Terminación (*Definition of Done -
DoD*).
• Pitch del Expositor (1.5 min): "Presentar la evidencia objetiva de
calidad y estabilidad del código."

DIAPOSITIVA 5: DEMOSTRACIÓN OPERATIVA DEL PRIMER INCREMENTO / PMV
----------------------------------------------------------------------
----------------------------------
• Esquema Visual: Mockup/Capturas de Pantalla del Software Ejecutable
+ Video Corto o Demo en Vivo (2 min).
• Contenido Clave:
  - Mantenimiento del alcance del PMV: Historias de Usuario HU-01, HU-
02 y HU-03 operativas.
  - Entorno de Despliegue (Emulador / Cloud / Staging).
  - Validación de Criterios de Aceptación con el usuario final.
• Pitch del Expositor (2.0 min): "Demostrar el software funcionando en
vivo o en video ejecutable."

DIAPOSITIVA 6: TABLERO DE MEDICIÓN DE VALOR E INDICADORES DE PROCESO
----------------------------------------------------------------------
----------------------------------
• Esquema Visual: Dashboard de Métricas Integradas (Métricas de
Proceso + Producto + Valor).
• Contenido Clave:

  - Avance de Planificación: Historias Planificadas vs. Completadas
(Velocidad / Burndown).
  - Métricas de Calidad de Software: Densidad de Defectos y Cobertura
%.
  - Métricas de Impacto Organizacional: Medición real alcanzada en el
PMV.
• Pitch del Expositor (1.0 min): "Demostrar con datos cuantitativos el
éxito de la iteración."

DIAPOSITIVA 7: TRAZABILIDAD INTEGRAL Y CONCLUSIONES TÉCNICAS
----------------------------------------------------------------------
----------------------------------
• Esquema Visual: Flujo de Trazabilidad Unificada (Problema ➔ Proceso
➔ Arquitectura ➔ Pruebas ➔ Valor).
• Contenido Clave:
  - Matriz de Trazabilidad que conecta las Unidades I y II.
  - Conclusiones principales del proceso de ingeniería aplicado.
  - Siguiente incremento planificado para la Unidad III.
• Pitch del Expositor (1.0 min): "Cerrar la exposición demostrando la
coherencia completa del trabajo."
