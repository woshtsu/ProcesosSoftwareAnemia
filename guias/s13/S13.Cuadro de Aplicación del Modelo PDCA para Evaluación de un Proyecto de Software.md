Escala de Seguimiento
| Estado  |     |     | Descripción  |     |     |     |
| ------- | --- | --- | ------------ | --- | --- | --- |
Abierto  Se identificó el hallazgo y aún no se inicia la acción correctiva.
En Proceso La acción correctiva está siendo ejecutada.
Verificado La evidencia demuestra que la acción fue realizada.
Cerrado  El hallazgo fue solucionado y la mejora quedó estandarizada.
Este formato permite que los estudiantes documenten la mejora continua del proyecto
de software mediante el ciclo PDCA, registrando tanto la fecha programada de la
acción correctiva como la fecha real de solución, facilitando el control y seguimiento
de los hallazgos identificados durante la evaluación final.
