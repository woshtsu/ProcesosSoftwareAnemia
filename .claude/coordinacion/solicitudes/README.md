# Solicitudes entre agentes

Una solicitud por archivo: `<PREFIJO>-###.md`, donde el prefijo identifica al agente que la **atiende**:

| Prefijo | Atiende | Plantilla |
| --- | --- | --- |
| `ORQ` | orquestador | `../plantillas/SOLICITUD.md` |
| `DOC` | revisor-documental | `../plantillas/SOLICITUD.md` |
| `DIAG` | diagramador | `../plantillas/SOLICITUD_DIAGRAMA.md` |
| `DEV` | desarrollador | `../plantillas/SOLICITUD.md` |
| `INV` | investigador | `../plantillas/SOLICITUD.md` |
| `CONV` | conversor-entregas | `../plantillas/SOLICITUD.md` |

Ver el flujo completo en `../PROTOCOLO.md`. Registrar cada solicitud también en `../TABLERO.md` (sección *Solicitudes abiertas*).
